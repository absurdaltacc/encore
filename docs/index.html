What Frontier does

Handcrafted, community-built, GPL-3.0. Every line auditable. No closed-source forks.

Bit-perfect 32-bit lossless

Direct hardware audio pipeline bypassing Android's 48 kHz mixer resampling. Native decoding for 24-bit/192 kHz FLAC, ALAC, WAV, and immersive multichannel containers. Real-time container, codec, sample rate, bit depth, and bitrate inspector built into the Now Playing menu.

7.1.4 binaural HRTF spatial audio

Custom binaural HRTF engine decodes multi-channel spatial audio into physical 3D acoustic coordinates (CICP 19: L, R, C, LFE, side surrounds, rear surrounds, 4 overheads). Valve Steam Audio acoustic pipeline recreates natural room depth in standard stereo headphones.

1-click Spotify library sync

Bring your Liked Songs and personal playlists in with one tap using secure RFC 7636 PKCE OAuth. No token pasting, no API setup. Tokens refresh silently and are stored in Android Keystore hardware encryption. Spotify becomes a catalog reference; playback streams from higher-fidelity sources when available.

Studio-grade parametric EQ

15-band parametric equalizer with variable Q factors and gain compensation. 5,000+ AutoEQ profiles for instant one-tap target compensation for popular over-ear, on-ear, and IEM headphones. Warm tube saturation and dynamic limiter add gentle analog harmonic drive without digital harshness.

One library, many sources

Qobuz, Tidal, Deezer, Amazon Music, Apple Music catalog matching. Local FLAC/ALAC/WAV playback. Optional private cloud libraries via TorBox and RealDebrid. Smart canonical-id resolution means a track you liked on Spotify can play back from any source you trust.

Zero ads, zero telemetry

No banner ads, no popups, no commercial breaks. No third-party analytics, behavioral tracking, or data profiling. Firebase Auth is included for optional cloud sync, but no google-services.json ships in the repo — the app builds and runs fully offline without it. Auditable source under GPL-3.0.

Install Frontier

Android 8.0 (Oreo) or newer. ARM, ARM64, x86, x86_64 — all supported from a single APK.

Option A — Pre-built APK

Download the latest signed release from GitHub Releases. Easiest path — no build tools required.

  1. Download frontier.apk from GitHub Releases
  2. Open the file on your Android device (Android 8.0+)
  3. If prompted, tap Allow from this source
  4. Launch Frontier
Get the APK →

Option B — Build from source

Clone and build with Gradle. Requires JDK 17+, Android SDK 36, NDK 28.2.13676358, CMake 3.22.1.

git clone https://github.com/absurdaltacc/encore.git
cd encore
./gradlew :app:assembleDebug
# → app/build/outputs/apk/debug/frontier.apk
